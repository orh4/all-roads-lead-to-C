# What I Learned
## How Types are Determined
Even if you explicitly define the type of an expression (eg. ```float num = 22/7```), it's type is ultimately determined by the type of it's operands.

```
float num = 22/7;
printf("%.2f", num); // outputs 3.00 since both operands are integers.

float num = 22.0/7;
printf("%.2f", num) // outputs 3.14 since at least one of it's operands is a float.
```

# Strings
Not all character arrays in C are strings. A character array can techinically contain a "string", but if it doesn't contain a null terminator, a string is not constituted, or at least, the string is not terminated.


All strings are character arrays, but not all character arrays are strings.


This is also the reason why strings (character arrays) in C contain an extra element in it's index.

# Slicing of Arrays
There is no native "slicing" of arrays in C. However, there are methods in order to get a specfic range of values from an array.


You can "slice" an array in C by either iterating over an array using a for loop and storing each element iterated over in a specified range OR you can use pointers whilst formating your strings ```printf("%.4s", name); // prints the first 4 characters```.
