# What I Learned:
## Basics
- Every C program uses libraries, which gives the ability to execute functions when necessary.
- It is important to add a ";" after every line we write in C to indicate when a line terminates.
- To use the "printf" function, we must add the "<stdio.h>" include directive (like this: "#include <stdio.h>") to use it in our program.
- Admittedly, this makes it clear to me that C is very focused on barebones and efficient programs, with no extra fluff in between, even for print statements!

## Printing
I learned about the "main" function, which is where all the code in our program will run.
In ```int main() {}```, the "int" before the function indicates that it will return an integer value.
If the function returns a value of 0, it ran successfully, and if it returns a value greater than 0 (eg. 1), then it indicates a failure.
Hence, we add an ```return 0;``` to the end of our "main" function to make sure it ends successfully.

## Variables and Types:
Variables have several types, such as:
- Integers: Self-explanatory, numbers which are either positive or negative. (Defined using char, int, short, long, long long)
- Unsigned integers: Only positive numbers, defined by adding the keyword/prefix "unsigned". (Defined using unsigned char, unsigned int, unsigned short, unsigned long, unsigned long long)
- Floating point numbers: Real numbers, numbers that can be expressed in the form of a fraction, they include decimals. (Defined using float and double)
- Booleans: true and false values. (Defined using bool)


Multiple variables of one type can be defined in one line, as so:

```int a = 0, b = 1, c = 2, d = 3, e = 4;```

## Arrays
Arrays are special variables, as they can store multiple (homogenous) values within themselves w organised with an index.

The syntax of an array is like this:

```int numbers[10]; // defines an array of 10 integers.```

You can assign values to each index of an array, like so:
```numbers[0] = 19;```


You can make the value of a variable be equal to the value of an element in an array, like so:

```int var = numbers[0];```

## Multidimensional Arrays
This was a little surprise for me. Normally in Python, we would need to use the "numpy" library in order to create such arrays (at least that's the gold standard), but here in C, it is built in!
It's syntax is pretty simple. Pretty similar to that in Python using the "numpy" module.
For an array ```int foo[x][y]```, ```x``` defines the number of rows and ```y``` defines the numbers of columns.

To define a 2-D array filled with integers, you write:
```int foobar[3][3];```


You can also create an array without defining the first index, as the compiler would just know it's a 2-D array, but you HAVE to fill in the second index.
i.e. ```int foobar[][3];``` is also valid!


Strings are an array of characters! Interesting..
i.e. ```char name[] = "John";```


Here is an example of a 2-D array:

```
int a[3][3] = {
    {1,2,3},
    {4,5,6},
    {7,8,9}
};
```


You can also initialize an array like this:

```int a[3][3] = {1,2,3,4,5,6,7,8,9};```

- Take a look at the array. Every 3 elements constitute one row, as defined by the shape of the array.


Similar to normal arrays, you can also set the value of a variable to the value of an element of a multidimensional array.

```int var = a[2][0];```

## Conditions
It's just simple if statements. Nothing special.
The syntax of an if statement in C is as so:

```
if (CONDITION) {
    CODE
}
```


If statements in C also include "else" conditions, like so:

```
if (a > b) {
    printf("a is more than b.");
} else {
    printf("b is more than a.");
}
```


If statements can be "chained" together, forming ``else if``` conditions, like so:

```
if (a < b) {
    printf("a < b");
} else if (a == b) {
    printf("a == b");
} else {
    printf("a > b");
}
```

- The "AND" and "OR" operators in C are ```&&``` and ```||``` respectively.
- The "NOT EQUAL" operator in C is ```!```. (eg. ```if (target != 10) {printf("Target is not equal to 10.");})
- The comparison operators (<, >) work as well.


- P.S. Semicolons at the end of if statements in C do nothing. People on StackOverflow aren't so nice.. (https://stackoverflow.com/questions/846804/semicolon-at-the-ends-of-if-statements-and-functions-in-c#846819)

## Strings
As said before, strings are an array of characters.
The basic syntax of strings are as so:

```
char string[] = "String";
```

- The ```[]``` in the above example indicates to compiler to automatically calculate the size of the string.


You can define the size of a string by defining it in the square brackets, like so:

```
char name[11] = "John Smith";
```


Formating strings with printf is pretty straightforward.

```
For:
= Integers: %d
=  Floats: %f
=  Strings: %s
= Characters: %c

... and many more.
```


To use functions such as ```strlen()```, ```strncmp()```, and ```strncat()```, you have to add the "<string.h>" include directive in your C program.
- The basic functions in this library are:

```
strlen(INPUT) // Calculates the length of the INPUT string.

strncmp(COMP, STN, LEN) /* Compares the first LEN (integer) values of the COMP string to the STN string
It produces either a 0 (true) or 1 (false) value.*/

Alternatively, there is strcmp, but it is "unsafe" apparently..

Finally, there is:
strncat(DEST, SRC, LEN) // Concatenates the first LEN (integer) values of the SRC string to the DEST string.
```
